## 🔬 Projects

- **4×4 Network-on-Chip (NoC) in Verilog/SystemVerilog**  
  Designed a 2D mesh NoC with XY routing, modular router design, and simulation-based verification to understand on-chip communication and scalability.

- **Snake Game using Ripes I/O Ports**  
  Implemented the classic Snake game using RISC-V assembly on the Ripes simulator, driving LED-matrix-style output via memory-mapped I/O and handling real-time user input.

- **Face Authentication System via Signal & Image Processing**  
  Built a non-ML biometric authentication pipeline using LBP, DFT, and SSIM for textural, spectral, and structural feature extraction, achieving robust webcam-based face matching.

- **FPGA-Based Hand Cricket Game**  
  Designed a modular SystemVerilog architecture with FSM-based game control, debounced inputs, and LED display driver, verified in simulation and deployed on an Artix-7 FPGA for real-time gameplay.
