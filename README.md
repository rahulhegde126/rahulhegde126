2. FPGA-Based Hand Cricket Game

Designed a modular SystemVerilog architecture with input capture, comparator, accumulator, and LED display driver for real-time score tracking.

Implemented simultaneous input capture using edge-triggered gating logic, ensuring fair and synchronous player inputs.

Built an FSM-based game controller to handle state transitions, OUT detection, and score updates, with debounced pushbutton control.

Verified and deployed on Xilinx Artix-7 FPGA, using simulation testbenches for functional verification and achieving smooth on-board gameplay.
